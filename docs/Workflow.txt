Module 1: CLI Interface

Description:
The CLI Interface serves as the entry point of the DevOps Automation Suite. It provides a command-line interface that accepts user commands, parses them using argparse, validates the input, and routes execution to the appropriate module. This module establishes a modular and scalable architecture, allowing each DevOps feature to be implemented independently while keeping the application organized and maintainable. It also provides built-in help and usage information for all available commands.

Module 2: Configuration & Reporting

Description:

The Configuration & Reporting module serves as the central configuration and reporting engine of the DevOps Automation Suite. It is responsible for loading application settings from JSON and YAML configuration files, managing configurable project parameters, and providing a reusable reporting framework. It generates reports in TXT, CSV, JSON, and HTML formats, enabling other modules to present their results in a consistent and organized manner. By centralizing configuration management and report generation, this module improves maintainability, reusability, and scalability across the entire project.
